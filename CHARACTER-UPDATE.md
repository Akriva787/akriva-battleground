# Tactical human update

Ranger Tactical replaces the previous sci-fi default with a human-scale masked military operator, fabric uniform, detailed vest, gloves and boots, using the CC BY model credited in ASSET-NOTICES.md. Seven outfit choices share this mesh. Tactical humans is the default gallery filter; All characters retains the earlier stylized extras. A one-time preference migration selects Ranger Tactical on the first load of this release; later selections persist.

This brings the silhouette and clothing closer to a tactical battle-royale style, but does not reproduce PUBG faces, clothing, assets or visual quality exactly. White-dress/facial reference characters remain unimplemented.
