# Classic Battleground character

The default character now uses the downloaded helmet / white shirt / tie / jeans mesh credited in ASSET-NOTICES.md. It has a custom anatomical smooth-weight rig and 20 baked idle/walk/run frames, with rifle-hold IK for the arms. The integrated helmet is not covered with a second helmet mesh when collecting helmet loot; gameplay protection still applies.

The character frame buffer loads on demand from classic-character.bin; the metadata and texture atlas are in classic-data.js. Include both files when hosting the source. This is a custom web-game adaptation, not the original PUBG rig, facial animation, shaders or gameplay fidelity. Mobile hardware performance remains unverified.
